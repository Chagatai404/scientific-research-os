What you should be able to explain
Distinguish a population from a sample, and explain why more observations cannot repair a biased selection process.

01 · Start with the population

A research question names something we want to learn about. Before choosing observations, define which units belong to that population and which measurements matter.

Definition

A sample is the collection of units selected for observation. Its relationship to the population determines what conclusions are justified.

02 · See the selection process

The selected observations are part of a larger collection. The diagram makes that relationship visible; a good sampling design must also explain how selection happens.

Think before revealing

If you collect more observations using the same biased selection process, which problem remains?

Hint · Separate precision from selection

Consider whether collecting more units changes which kinds of units can enter the sample.

Worked explanation

More observations may reduce random variability while leaving selection bias in place. Precision and representativeness are different properties.

03 · Connect intuition to a formula

Under independent observations with finite common variance, the standard error of the sample mean decreases with the square root of sample size.

SE(x̄) = σ / √n

σ: population standard deviation. n: number of observations. Production equations use the bundled math renderer; this specimen uses text notation.

Quadrupling n halves this standard error under the stated assumptions. The formula describes variability, and does not establish that a selection process is unbiased.
