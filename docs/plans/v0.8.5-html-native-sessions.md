## ADR: HTML-primary, structured underneath

Keep each existing Markdown path and complete original frontmatter/body for native
search, backlinks, Excalidraw and older parsers. A generated fenced ros-session
embed points to sibling HTML and JSON. JSON owns session content and interaction
events; HTML and bridge are projections. Legacy bytes are backed up separately.
Agent changes use a central Python API, not editing derived HTML. Detect conflicting
bridge edits and refuse overwrite; explicitly import reviewed Markdown changes.
Existing learning/evidence/research schemas remain authoritative in their domains.
Session JSON records raw responses and pending review, references canonical learning
IDs and leaves promotion/retention assessment to existing reviewed workflows.

## Dependencies and security

Python standard library for portable creation/migration. Plain CommonJS Obsidian
plugin avoids a build toolchain; runtime CSS/JS shared under .research-os/runtime.
Bundle a deterministic local math dependency with license and integrity inventory;
no essential CDN. Export inlines approved runtime/resources only.
Use opaque-origin iframe sandbox="allow-scripts" without allow-same-origin.
Host builds a sanitized document and injects restrictive CSP before any content.
No parent API, Electron, Node or file access is passed into the iframe. Authenticate
messages by frame window plus per-load token and session ID; validate bounded event
shapes, allowed question IDs and event IDs; serialize state writes. Host resolves
only explicitly approved resources within the session/runtime directories, rejects
traversal and remote URLs, and never accepts arbitrary read/write requests.
Resource execution needs explicit local authoring/trust; generated HTML must not
grant itself additional privileges. Export cannot provide an Obsidian state bridge.

Sources: [Obsidian API](https://github.com/obsidianmd/obsidian-api/blob/master/obsidian.d.ts),
[Markdown postprocessing](https://github.com/obsidianmd/obsidian-developer-docs/blob/main/en/Plugins/Editor/Markdown%20post%20processing.md),
[iframe isolation](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe),
[srcdoc](https://developer.mozilla.org/en-US/docs/Web/API/HTMLIFrameElement/srcdoc).
