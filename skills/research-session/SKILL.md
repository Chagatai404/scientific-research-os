# Research Session

Read:
- `references/RESEARCH_PROTOCOL.md`
- `references/AGENT_POLICY.md`
- `references/SOURCE_POLICY.md`

## Start

1. Read the current research state if the project has one.
2. State today's question.
3. Choose the mode:
   - learning,
   - literature,
   - derivation,
   - experiment,
   - coding,
   - review.
4. Open/create a live Obsidian research-session note when configured.
5. If the session includes literature that may determine a model, implementation, or hypothesis:
   - write a neutral discovery question before inspecting implementation-specific assumptions;
   - decide what project context is genuinely necessary to define the search scope;
   - keep discovery, verification, and reconciliation as separate stages.

## During

- Use skills rather than improvising recurring workflows.
- Delegate independent specialist checks when they add value.
- Protect independent reviewers from authoring-agent reasoning when practical.
- Keep facts, assumptions, interpretations, and speculation distinct.
- Track whether important evidence was independently discovered or inherited from the project.
- Seek counterevidence for consequential scientific decisions.
- Persist evidence in the Git research repo.
- Persist understanding in Obsidian.
- Do not let notebooks become the only implementation of reusable methods.

## End

Record:
- I learned:
- The evidence says:
- I still do not know:
- Decisions made:
- Next human decision/action:

Update research state only with human-accepted conclusions.
