# Study Source

Read `references/SOURCE_POLICY.md`.

1. Record bibliographic/source metadata.
2. Record how the source entered the workflow:
   - independent discovery,
   - inherited project citation,
   - user-provided source,
   - citation chain,
   - targeted reconciliation search.
3. Identify why the source is credible and what role it plays:
   - evidence,
   - reference,
   - review,
   - teaching aid.
4. Separate:
   - source claim,
   - evidence/method,
   - source interpretation,
   - your interpretation.
5. Capture exact page/section/equation/figure/timestamp where possible.
6. Record the claim envelope needed to interpret each important passage:
   - system/population,
   - particle/process,
   - material/detector,
   - energy/parameter regime,
   - observable,
   - coordinate/origin convention,
   - model/approximation,
   - validity range.
7. For quantitative claims, preserve the exact source-stated value and units. Record conversions or derived values separately and show the derivation.
8. Identify what the source does NOT establish.
9. If the source contains multiple treatments of the same phenomenon, keep them separate and record which observable, approximation, or convention each treatment describes.
10. Mark equations that require separate derivation.
11. Link claims to active research questions/hypotheses only after extracting the source on its own terms.
12. For papers, look for available code/data and a minimal reproduction path.
13. If the source is being used to choose or justify a scientific model, check whether an independent neutral literature-discovery pass occurred first. If not, request one before treating the source set as representative.
14. If a key claim matters to research, ask the source-verifier to independently verify it. Provide the verifier the claim and source, but not your conclusion when practical.
15. If a mechanistic interpretation is inferred from correlation or from evidence in a different regime, label it as an interpretation or transferred hypothesis rather than a verified source claim.
