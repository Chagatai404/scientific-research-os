# v0.4 implementation decision

Slice 0 inspected the agents, research/source/agent policies, skill routing,
Markdown evidence template, standard-library scripts, installer generation and
unittest suite. v0.3 already supplies atomic claims, exact values/units, envelopes,
independent verification, transfer labels, epistemic distinctions and human gates.
Evidence persistence is currently Markdown; the learning parser is unrelated and
will remain separate. There is no evidence schema or database to migrate.

Use one standard-library Python EvidenceAtom representation and JSON serialization
in `scripts/validate_evidence.py`, rather than maintaining a second JSON Schema
validator. The same module owns structural checks, explicit verification receipt
checks, dependency-aware reuse and compact Markdown rendering. A receipt binds an
independent source reconstruction to a content fingerprint. It detects subsequent
edits and structured mismatches; it is not an authenticated signature or a test of
scientific truth. Human/source verification remains necessary.

Add focused fixtures/tests and one format reference. Update the three agent
contracts, two research skills, canonical policy routing, README and VERSION.
Install the evidence helper alongside research skills and bundle the compact
format reference into relevant standalone agents. Existing Markdown notes remain
readable; adoption is opt-in, but structured records are strictly validated.
No provider selection, infrastructure or scientific prose inference is added.
