# Evidence Ladder

Use this lightweight label for internal research maturity.

- **E0 — Idea/speculation:** no direct supporting result yet.
- **E1 — Theoretical argument:** derives plausibility under stated assumptions.
- **E2 — Toy simulation:** effect appears in a simplified synthetic system.
- **E3 — Controlled simulation:** effect survives controlled confounder tests.
- **E4 — Realistic detector/domain simulation:** effect survives realistic modeling.
- **E5 — Real data:** effect is observed in real measurements/data.
- **E6 — Independent reproduction:** separate analysis reproduces the result.

The ladder is not a universal hierarchy of scientific truth. It is a project-management label for how directly this project's claim has been tested.
