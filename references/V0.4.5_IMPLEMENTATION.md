# v0.4.5 — Learning architecture and academic workflow

Extend schema 1 with optional retention targets, goal membership and course
membership. Existing records need no migration and missing retention targets mean
unspecified, never an inferred core assignment.

This release adds:
1. Retention targets for selective long-term memory.
2. Goal-oriented knowledge maps.
3. A university-course learning mode.
4. Handwritten-note → LaTeX transcription support.

`learning_state` = what evidence says about understanding/retrieval.
`retention_target` = how important long-term unaided availability is.
These remain separate. Retrieval history stays authoritative; derived graphs do
not become independent ledgers. Permanent-note promotion remains a human choice.

Retention priority must not be inferred solely from graph centrality, AI
confidence, note frequency, or arbitrary numeric scoring.

Keep assessment and prerequisite readiness conservative and unchanged. Expose
retention policy separately in views: reference records carry no routine spaced
review recommendation, even when historical evidence has an overdue horizon.
Do not erase historical dates, failures, or stale evidence. A reference target
does not itself satisfy a prerequisite; explicit learning design must distinguish
lookup-supported application from capabilities requiring fluent recall.

Goal and course selectors reuse prerequisite closure and diagnostics. One record
can belong to multiple contexts without duplication. Course study builds on the
learning protocol without the research cycle unless a substantive research
question is explicitly pursued. Transcription preserves mathematical content and
reports uncertainty and corrections separately; it adds no OCR/compiler dependency.

Installer discovery and shared-reference bundling already support both new skills
symmetrically for Claude and Codex. Keep scripts/tests standard-library only.

Defer Geant4 support, ML/QML methodology, scientific-compute tool packs, runtime
scientific environment probing, experiment manifests, and HPC/cloud tooling to
v0.5 or later. Do not publish, tag, or merge this branch.

Implement sequential slices: contract; retention; goals; courses; transcription;
integration. Run the full unit suite and validator per slice, inspect diffs, and
commit each slice. Set VERSION to 0.4.5 only after release gates pass.
